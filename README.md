# The Travel House — Premium Website (React + Vite + React Router)

    npm install
    npm run dev        # http://localhost:5173
    npm run build      # production build -> /dist

## What's inside
- 12 routes: Home, About, Services (+7 detail pages), Tour Packages (75 packages, filter/sort/search),
  Package Detail (itinerary, inclusions, policies, booking form), Category pages, Gallery, Testimonials, Contact, 404
- Premium UI: logo-matched blue/orange theme, preloader, hero slider with timer bars, 3D tilt cards,
  sliders with autoplay + drag, offer countdown timer, mega menu, mobile drawer, animated counters,
  scroll progress bar, lightbox, quick-view & enquiry modals, floating WhatsApp/Call buttons
- Enquiry forms open WhatsApp with the details pre-filled (no backend needed)

## Edit content
- Phone / address / email / hours / stats / FAQs / reviews: `src/data/data.js`
- Packages: `src/data/packages.json` (title, duration, price, destinations, activities, themes, image id)
- Logo files: `public/logo.jpg`, `public/logo-mark.png`, `public/favicon.png`
- Colors: CSS variables at the top of `src/styles.css`
